# System Architecture

## TrafficData
Stores traffic information.

Attributes:
- district
- congestionLevel
- updateTime

## TrafficAPI
Retrieves traffic data.

Method:
- getTrafficData()

## MapManager
Displays map and traffic information.

Method:
- displayMap()

## User
Handles user interaction.

Method:
- selectDistrict()

## MainApp
Controls application execution.

Method:
- run()
